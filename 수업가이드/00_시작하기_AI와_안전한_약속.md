## STEP 1. AX와 AI 용어, 내 말로 정리하기 (10분)

오늘 수업의 이름은 "AI로 만드는 나만의 엑셀 정리·집계 도우미"입니다. 먼저 자주 나오는 말 세 가지를 쉬운 말로 맞춰 봅니다.

**따라 하기**

1. 아래 표를 읽고, 오른쪽 "우리 회사 예시" 칸이 이해되는지 확인하세요.
2. "📝 직접 입력해보기"의 빈칸에 **내 업무 예시**를 한 줄씩 적어 보세요.

| 말 | 한 줄 뜻 | 우리 회사 예시 |
|---|---|---|
| **AX** (AI Transformation, 인공지능 전환) | AI를 일부 업무에 써 보는 데서 끝나지 않고, **업무·서비스·조직이 일하는 방식과 가치를 바꾸는 것** | 매달 손으로 하던 월 실적 집계를 도구로 바꾸고, 보고서도 AI와 함께 만든다 |
| **생성형 AI** | 질문이나 지시를 보고 **글·이미지·코드 같은 새로운 결과물을 만들어 내는** 인공지능 | ChatGPT, Gemini에게 "이 숫자로 보고서 써 줘"라고 하면 글이 나온다 |
| **머신러닝** (기계학습) | 컴퓨터가 **많은 데이터를 보고 스스로 규칙과 패턴을 배우는** 방식 | 지난 3년 불량 데이터를 보고 "이런 조건에서 불량이 많다"는 패턴을 스스로 찾는다 |

💡 **쉬운 설명:** 새로 온 신입에게 일을 가르치는 것과 비슷해요.
- **머신러닝**은 신입이 **수백 장의 지난 보고서를 읽으며 스스로 요령을 익히는 것**입니다. 선배가 규칙을 하나하나 알려 주는 게 아니에요.
- **생성형 AI**는 요령을 익힌 신입이 **새 보고서를 직접 써서 내는 것**입니다.
- **AX**는 한 사람이 보고서만 잘 쓰게 되는 게 아니라, **부서가 일하는 방식 전체가 새로 바뀌는 것**입니다. (예: 월 마감이 8시간에서 3시간으로 줄고, 그 시간에 분석을 한다)

📝 **직접 입력해보기**

| 질문 | 내 답 |
|---|---|
| 내가 매달 반복하는 엑셀 업무 한 가지는? (예: 지점별 월 매출 집계) | |
| 그 일을 AI가 도와주면 가장 먼저 바뀌었으면 하는 것은? (예: 집계 시간, 숫자 실수) | |

<div data-callout="info">

**🎓 자격증 연결 (1·2·3번):**
- **AX** = AI를 업무·서비스·조직 전반에 도입해 **일하는 방식과 가치를 바꾸는 일**. (종이를 파일로 바꾸는 것은 디지털화, 직원 수를 줄이는 것은 AX의 목적이 아니에요.)
- **생성형 AI** = 글·이미지·코드처럼 **새로운 결과물을 만들어 내는** AI.
- **머신러닝** = 데이터를 보고 **스스로 규칙과 패턴을 배우는** 방식. (사람이 모든 규칙을 일일이 프로그래밍하는 것은 전통적인 방식이에요.)

</div>

## STEP 2. 회사 자료를 AI에 넣기 전 약속 3가지 (10분)

AI는 편리하지만, 입력한 내용은 **회사 밖의 서비스로 나갑니다.** 그리고 AI는 **틀린 말을 그럴듯하게 하기도** 합니다. 두 가지를 직접 눈으로 확인해 봅니다.

**따라 하기**

1. 아래 "AI에 넣어도 되는지" 표를 읽고, 내 업무 자료를 하나 떠올려 보세요.
2. Gemini(또는 ChatGPT) 새 대화를 열고, 아래 **확인 질문**을 그대로 입력하세요.

```
우리 회사 2026년 7월 월 매출 합계가 정확히 얼마인지 알려줘.
```

3. AI가 어떻게 답하는지 읽어 보세요. 그리고 한 번 더 이렇게 입력해 보세요.

```
2026년 7월 서울 지점 사과 판매 수량을 정확히 알려줘. 모르면 모른다고 해.
```

💡 **쉬운 설명/예시:** 보통 이런 모습이 나옵니다.
- 첫 질문: AI는 우리 회사 자료를 모릅니다. 좋은 AI는 "자료가 없어서 알 수 없어요"라고 답합니다. 그런데 가끔 **그럴듯한 숫자를 지어내서** 말하기도 해요. 이것을 **환각(할루시네이션, hallucination)** 이라고 합니다.
- 둘째 질문: "모르면 모른다고 해"라는 **규칙 한 줄**을 넣으면 지어내는 일이 줄어듭니다. 이 규칙은 STEP 3에서 요청문 틀의 한 칸이 돼요.

**AI에 넣어도 되는지 판단표**

| 질문 | 예 | 아니오 |
|---|---|---|
| 거래처·사람 이름이 들어 있다 | **이름을 가려서(가명으로 바꿔서)** 넣는다 | 그대로 넣는다 |
| 단가·계약 조건처럼 밖에 나가면 안 되는 열이 있다 | 그 열은 **빼고** 넣는다 | 그대로 넣는다 |
| 원본 파일 전체를 넣으려 한다 | **집계표**(합계만 모은 표)만 넣는다 | 원본을 통째로 넣는다 |
| AI의 답을 보고서에 그대로 쓰려 한다 | **숫자를 내가 다시 확인**한 뒤 쓴다 | 그대로 쓴다 |

📝 **직접 입력해보기** — 내 업무 자료 하나로 판단해 보세요.

| 내 자료 | 이름이 들어 있나? | 밖에 나가면 안 되는 열이 있나? | 어떻게 넣을까? (가리기 / 빼기 / 집계표만) |
|---|---|---|---|
| (예: 지점별 월 매출표) | 예 (지점 담당자 이름) | 아니오 | 이름을 가리고 집계표만 |
| | | | |

<div data-callout="warning">

**주의:** 회사마다 AI 사용 규정이 있습니다. 규정이 있다면 **규정이 먼저**예요. 모르겠으면 보안 담당자에게 먼저 물어보세요. 오늘은 **연습용 가짜 자료**로만 합니다.

</div>

<div data-callout="info">

**🎓 자격증 연결 (5번·9번):**
- **5번:** 외부 AI에 회사 자료를 넣을 때 가장 알맞은 행동은 **이름·금액 같은 민감한 정보를 가리거나 빼고 입력하는 것**입니다. (비밀번호를 같이 넣거나, 신경 쓰지 않는 것은 틀린 행동이에요.)
- **9번:** 생성형 AI가 사실이 아닌 내용을 사실처럼 그럴듯하게 만들어 내는 현상 = **환각(할루시네이션)**.

</div>

- [ ] "이름은 가린다 / 필요 없는 열은 뺀다 / 집계표만 넣는다 / 답은 내가 확인한다"를 말할 수 있다

## STEP 3. 요청문 6칸 틀로 첫 요청문 만들기 (10분)

AI에게 "보고서 써 줘"라고만 하면 AI가 **마음대로 채웁니다.** 요청문(프롬프트)을 **6칸**으로 나눠서 쓰면 원하는 결과가 훨씬 잘 나옵니다. 이 칸은 오늘 계속 쓰게 돼요.

**프롬프트(요청문)** = AI에게 하는 질문이나 지시문입니다.

**따라 하기**

1. 아래 6칸 틀을 읽으세요.
2. 아래 "예시 요청문"을 읽고, 어느 줄이 어느 칸인지 연결해 보세요.
3. `첨부자료/빈칸_틀_프롬프트_카드.md` 또는 아래 **빈칸 카드**를 복사해, 내 업무 한 가지를 채워 보세요.
4. 완성한 요청문을 Gemini에 붙여넣고 답을 확인하세요.

| 칸 | 한 줄 설명 | 예시 |
|---|---|---|
| **[역할]** | AI가 누구인지, 읽는 사람은 누구인지 | "너는 제조 회사 경영지원팀 선배야. 임원에게 보고하는 글을 쓴다" |
| **[목표]** | 끝났을 때 무엇이 있어야 하나 | "3분기 매출을 임원 보고용 3줄 요약으로 만들어 줘" |
| **[재료]** | AI에게 주는 자료 | "7월 18,461,000원 / 8월 20,647,000원 / 9월 18,533,000원" |
| **[할 일]** | 구체적으로 무엇을 할지 | "한 줄 결론, 3줄 요약, 눈에 띄는 점 1가지" |
| **[규칙]** | 꼭 지킬 것, **하지 말 것** | "숫자는 [재료]에 있는 것만 써. 모르면 '자료에 없음'이라고 써" |
| **[마지막 검사]** | 끝났는지 AI가 스스로 확인하는 방법 | "쓴 숫자가 [재료]에 모두 있는지 확인하고, 없으면 고쳐서 보내" |

**예시 요청문** (이대로 Gemini에 붙여넣어 보세요)

```
[역할]
너는 제조 회사 경영지원팀 선배야. 임원에게 보고하는 글을 쉬운 말로 쓴다.

[목표]
아래 숫자로 3분기 매출 보고 요약을 만들어 줘.

[재료]
- 7월 18,461,000원 / 8월 20,647,000원 / 9월 18,533,000원
- 합계 57,641,000원

[할 일]
- 한 줄 결론 1개
- 3줄 요약
- 눈에 띄는 점 1가지

[규칙]
- 숫자는 [재료]에 있는 것만 써. 모르는 숫자는 만들지 마.
- 이유를 추측한 문장은 "추정:"이라고 표시해.
- 쉬운 말로, 한 쪽 이내.

[마지막 검사]
쓴 숫자가 모두 [재료]에 있는지 확인하고, 없으면 고쳐서 보내.
```

**빈칸 카드**

```
[역할]
너는 (누구)를 위해 (무엇)을 하는 (직업)이야. 읽는 사람은 (누구)야.

[목표]
(결과물 이름)을 만들어 줘. 끝나면 (무엇이 되어 있어야 하는지).

[재료]
- 내가 줄 자료:

[할 일]
1.
2.

[규칙]
- 꼭 지킬 것:
- 하지 말 것: (숫자 지어내지 마)

[마지막 검사]
끝내기 전에 (무엇)을 확인하고, 안 맞으면 (어떻게 하라).
```

💡 **쉬운 설명:** 요청문은 **주문서**와 같아요. "맛있는 거 주세요"는 아무거나 나오지만, "매운 정도는 보통, 양파 빼고, 2인분"은 원하는 것이 나옵니다. **[규칙]에 "하지 마"를 쓰는 습관**이 가장 효과가 커요.

📝 **직접 입력해보기** — 내 업무 하나를 아래 표로 먼저 정리한 뒤 카드에 옮겨 쓰세요.

📌 **오늘 배운 것 정리**
- **AX**는 AI를 도입해 일하는 방식과 가치를 바꾸는 것, **생성형 AI**는 새 결과물을 만들어 내는 AI, **머신러닝**은 데이터에서 규칙을 스스로 배우는 방식이에요.
- AI에 회사 자료를 넣을 땐 **이름은 가리고, 필요 없는 열은 빼고, 집계표만 넣고, 답은 내가 확인합니다.**

- 요청문은 **6칸**으로 쓰고, **"하지 마" 규칙**을 꼭 넣으세요.

## 용어 사전

| 용어 | 쉬운 뜻 |
|---|---|
| AX (AI Transformation) | AI를 도입해 업무·조직이 일하는 방식과 가치를 바꾸는 것 |
| 생성형 AI | 질문을 보고 글·이미지·코드를 새로 만들어 내는 AI (ChatGPT, Gemini 등) |
| 머신러닝 | 데이터를 보고 컴퓨터가 스스로 규칙과 패턴을 배우는 방식 |
| 프롬프트(요청문) | AI에게 하는 질문이나 지시문 |
