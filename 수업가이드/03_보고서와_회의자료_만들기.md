## STEP 1. 앱③ 열고 설정하기 (5분)

앱③은 **AI를 쓰지 않아요.** 내 숫자에서 요청문을 **자동으로 만들어 주는 도우미**예요. AI는 Gemini에서 씁니다.

**따라 하기**

1. `3_보고서앱.html`을 여세요. 위쪽에 `① 자료 / ② 설정 / ③ 요청문 / ④ 다듬기` 네 단계가 보여요.
2. 정리된 `매출 (수출입)_정리됨.csv`를 점선 칸에 끌어다 놓으세요. (없으면 **`매출 (수출입)`** 버튼)
3. `② 무엇을 만들까요?` 화면이 열리면 아래처럼 맞추세요.

   | 칸 | 고를 것/쓸 것 |
   |---|---|
   | 쓸 AI 도구 | `Gemini Canvas (보고서·회의자료 웹페이지까지)` |
   | 누가 읽나요? | `사장님·임원` |
   | 분량 | `보통 (A4 반 장)` |
   | 회의자료 장수 | `5` |
   | 문서 제목 | `3분기 매출 보고` |
   | 어느 기간의 자료인가요? | `2026년 3분기` |
   | 꼭 넣고 싶은 말·강조할 점 | `수출이 늘어난 점을 강조하고 싶어요` |

4. 아래 **"가릴 것 고르기"** 에서 **`거래처 가리기`** 가 체크되어 있는지 확인하세요. (가린 이름은 `거래처A`, `거래처B`… 로 바뀌어요.)
5. **[다음: 요청문 만들기 →]** 를 누르세요.

💡 **쉬운 설명/예시:** **읽는 사람**을 바꾸면 요청문이 달라져요. 예를 들어 `사장님·임원`은 "바쁘고 숫자를 많이 보고 싶어 하지 않는다. 결론을 먼저 알고 싶어 한다"가 들어가고, `고객사·외부`는 "내부 사정이나 민감한 숫자는 빼고 써 줘"가 들어가요. 같은 숫자도 **누가 읽느냐**에 따라 쓰는 방법이 달라져요.

📝 **직접 입력해보기** — 내 업무에서는 이렇게 정하겠다는 것을 적어 보세요.

| 질문 | 내 답 |
|---|---|
| 내가 만들 보고서는 누가 읽나요? | |
| 그 사람이 가장 알고 싶어 하는 것은? | |
| 꼭 강조하고 싶은 점 한 가지는? | |

- [ ] `거래처 가리기`가 체크되어 있다
- [ ] `③ 요청문` 단계로 넘어왔다

## STEP 2. 보고서·회의자료 내용 먼저 만들기 (8분)

**한 번에 웹페이지까지 시키지 않아요.** 먼저 **글(내용)** 을 만들고, **숫자가 맞는지 검산**한 뒤에 모양을 입힙니다. 틀린 숫자가 예쁜 페이지에 들어가면 더 위험하니까요.

**따라 하기**

1. 화면에서 **`내용 먼저 만들기`** 가 선택되어 있는지 확인하세요. 아래에 **"같은 대화에서 이어서 붙여넣으세요"** 안내와 순서가 보입니다.
2. 요청문 상자를 훑어보세요. `[역할] [목표] [재료: 확인된 숫자] [읽는 사람] [강조할 점] [할 일 1] [할 일 2] [규칙] [출력 모양] [마지막 검사]`가 보이고, `거래처A` 같은 가명이 들어 있어요.
3. **[요청문 복사하기]** 를 누르세요.
4. Gemini를 열고 **새 대화**를 시작하세요. 입력창 근처 **도구 메뉴에서 `Canvas`를 켜세요.** (메뉴 이름과 위치는 바뀔 수 있어요. **안 보이면 손을 들어 알려 주세요.**)
5. 복사한 요청문을 **붙여넣기** 하고 Enter를 누르세요.
6. 답이 나오면 **맨 끝 "숫자 검산표"** 를 보세요. `근거 없음`이 **0개**여야 해요.

**AI의 답은 이런 모습이에요 (예시. 실제 답은 조금씩 달라요)**

```
## 임원 보고 요약
한 줄 결론: 3분기 매출은 57,641,000원이고, 수출이 늘어난 것이 8월 증가를 이끌었다.
3줄 요약
- 3분기 합계는 57,641,000원(36건)이다.
- 8월이 20,647,000원으로 가장 컸고 9월은 전달보다 10.2% 줄었다.
- 수출이 32,884,000원(57.0%)으로 내수(43.0%)보다 컸다.
눈에 띄는 점 2가지
- 수출 비중이 7월 43.9%에서 9월 69.0%로 늘었다 (구성 변화).
- 한 건(2026-09-13)이 6,136,000원으로 전체의 10.6%를 차지했다.
걱정되는 점
- 추정: 거래처A 한 곳이 35.5%를 차지해 한 거래처에 매출이 쏠려 있다.
다음에 할 일
- 거래처A 의존도를 낮출 방법을 (누가, 언제까지: 비워 둠)

## 숫자 검산표
| 글에 쓴 숫자 | 근거(위 재료의 어느 항목) |
| 57,641,000원 | 전체 금액 합계 |
| 10.2% | 월별 표의 9월 전달 대비 |
| 32,884,000원 | 구분별 표 수출 |
...
```

💡 **쉬운 설명/예시:** 요청문의 **`[마지막 검사]`** 줄 덕분에 AI가 답을 보내기 전에 스스로 한 번 확인해요. 그래도 AI가 "근거 없음 0개"라고 해 놓고 틀릴 수 있으니, **검산표를 내가 앱② 보고서의 숫자와 직접 비교**하세요. 앱②는 같은 입력에는 항상 같은 숫자를 내는, **믿을 수 있는 기준표**예요.

<div data-callout="warning">

**주의:** 검산표에서 하나라도 다르면 **그 문장을 고쳐 달라고** 말하세요. 예: `"9월 전달 대비 10.2%"가 표와 다릅니다. 표의 −10.2%에 맞춰 고쳐 줘.`

</div>

<div data-callout="info">

**🎓 자격증 연결 (10번):** AI가 만든 결과는 **사람이 사실과 숫자를 직접 확인(검산)한 뒤** 씁니다. 검산표와 앱② 보고서를 비교하는 이 습관이 바로 그거예요.

</div>

| 검산할 숫자 | 보고서(앱②)의 숫자 | AI 답의 숫자 | 맞나요? |
|---|---|---|---|
| 3분기 합계 | 57,641,000 | | |
| 9월 전달 대비 | −10.2% | | |
| 수출 비중 | 57.0% | | |

✅ **체크리스트**
- [ ] AI의 답에 `임원 보고 요약`과 `회의 자료 구성안`이 있다
- [ ] `숫자 검산표`의 `근거 없음`이 0개임을 확인했다
- [ ] 검산표의 숫자 세 개 이상을 앱② 보고서와 직접 비교했다

## STEP 3. 보고서를 웹페이지로 만들고 PDF 저장하기 (8분)

검산이 끝난 내용을 **읽기 좋은 웹페이지**로 만들어서 **PDF**로 저장해요.

**따라 하기**

1. 앱③으로 돌아와 **`보고서 웹페이지`** 를 누르세요. 요청문이 바뀌고, 아래 순서 안내가 나옵니다.
2. 요청문 상자를 보세요. `[화면 구성]`, `[모양 규칙]`, **`[인쇄 규칙]`** 이 들어 있어요. **[요청문 복사하기]** 를 누르세요.
3. **STEP 2와 같은 Gemini 대화**에서 입력창에 붙여넣고 Enter를 누르세요. (이어서 붙여넣어야 "바로 위에서 만든 요약"을 가져다 써요.)
4. Canvas에 보고서 웹페이지가 만들어지면 화면에서 읽어 보세요. 한 줄 결론, 핵심 숫자 3개, 그래프 2개가 있는지 보세요.
5. **웹페이지 코드를 전체 복사**하세요. 앱③의 `④ 다듬기` 단계를 열고 **"AI 답 붙여넣기"** 칸에 붙여넣으세요.
6. `웹페이지 코드로 보여요`라는 안내와 함께 **"완성 글"** 에서 `거래처A`가 `Sakura Parts`로 바뀌어 있어요. **[되돌린 웹페이지 받기 (.html)]** 를 눌러 파일을 저장하세요.
7. 저장한 `.html` 파일을 더블클릭해 브라우저로 열고, 키보드 **Ctrl+P** 를 누르세요.
8. 인쇄 창에서 **대상을 `PDF로 저장`** 으로 고르세요. **미리보기**에서 아래를 확인한 뒤 저장하세요.

   | 확인할 것 | 정상 모습 |
   |---|---|
   | 용지와 쪽 수 | A4 세로, 1~2쪽 |
   | 배경 | 흰색 (큰 색 배경이 없음) |
   | 그래프와 표 | 쪽 사이에서 잘리지 않음 |
   | 화면의 버튼 | 인쇄에 나오지 않음 |

💡 **쉬운 설명/예시:** **PDF는 웹페이지를 "인쇄해서 파일로 저장"** 한 거예요. 그래서 요청문에 **인쇄 규칙**을 따로 넣어야 해요. 규칙이 없으면 이런 일이 생겨요.
- 그래프가 쪽 사이에서 반으로 잘려요 → 규칙: "그래프·표가 쪽 사이에서 잘리지 않게(page-break-inside: avoid)"
- 인쇄에 [다음] 버튼이 같이 찍혀요 → 규칙: "화면에서만 보이는 버튼은 인쇄에서 숨겨"
- 잉크가 많이 들게 파란 배경이 나와요 → 규칙: "인쇄할 때는 배경을 흰색으로"

<div data-callout="warning">

**주의:**
- 요청문에 "외부로 데이터를 보내는 코드를 넣지 마"가 있어요. 그래도 **AI가 만든 코드는 믿기 전에 확인**하세요. 파일 안에 `http`나 `fetch` 같은 글자가 있으면 강사에게 알려 주세요.
- **Canvas 미리보기 창에서 인쇄가 막히면** 위 5~7번처럼 코드를 `.html`로 저장해서 브라우저로 열면 돼요.

</div>

- [ ] 미리보기에서 그래프가 잘리지 않고 버튼이 인쇄에 나오지 않는 것을 확인했다

## STEP 4. 회의자료를 웹페이지로 만들고 PDF 저장하기 (7분)

이번에는 **회의에서 화면으로 보여 줄 슬라이드**예요. 화면에서는 한 장씩 넘기고, 인쇄하면 **가로로 한 장이 한 쪽**이 돼요.

**따라 하기**

1. 앱③의 `③ 요청문`에서 **`회의자료 웹페이지`** 를 누르세요. 요청문 안에 `회의 자료 구성안 5장`이라는 글이 들어 있는지 확인하세요.
2. **[요청문 복사하기]** → **같은 Gemini 대화**에 붙여넣기 → Enter.
3. 만들어진 슬라이드에서 **[이전] [다음]** 버튼과 키보드 **← →** 키로 넘겨 보세요. **[전체 한 번에 보기]** 버튼도 눌러 보세요.
4. STEP 3과 같은 방법으로 코드를 `④ 다듬기`에 붙여넣고 **[되돌린 웹페이지 받기 (.html)]** 로 저장하세요.
5. 파일을 열고 **Ctrl+P** → `PDF로 저장` → **방향을 `가로`** 로 바꾸세요. 미리보기에서 **5장이 5쪽**(한 장이 한 쪽)으로 나뉘는지 확인하고 저장하세요.

💡 **쉬운 설명/예시:** 구성안의 5장은 대략 이런 모습이에요. **제목이 "결론 문장"** 인 게 포인트예요. 제목만 읽어도 이야기가 이어져요.

| 장 | 제목 (결론 문장) | 핵심 숫자 | 넣을 그래프 |
|---|---|---|---|
| 1 | 3분기 매출은 57,641,000원이었다 | 57,641,000원, 36건 | (큰 숫자) |
| 2 | 8월이 가장 컸고 9월에 줄었다 | 20,647,000원, −10.2% | 월별 막대 |
| 3 | 수출이 내수보다 커졌다 | 수출 57.0% | 100% 쌓은 막대 |
| 4 | 제어보드가 품목 매출의 절반 가까이다 | 46.9% | 큰 순서 가로 막대 |
| 5 | 한 거래처에 매출이 쏠려 있다 | 거래처A 35.5% | 순위 가로 막대 |

📝 **직접 입력해보기**

| 질문 | 내 답 |
|---|---|
| 내 업무 회의자료의 1장 제목을 "결론 문장"으로 써 보세요 | |
| PDF 미리보기에서 슬라이드는 몇 쪽이었나요? | |

---

✅ **체크리스트**
- [ ] 슬라이드를 [이전][다음]과 ← → 키로 넘겨 보았다
- [ ] 방향 `가로`로 PDF 미리보기를 확인했고 장수만큼 쪽이 나왔다
- [ ] 슬라이드의 숫자를 앱② 보고서와 두 개 이상 비교했다

## STEP 5. 요청문 만드는 법(결과물 파헤치기)과 내 업무 적용 로드맵 (7분)

오늘 쓴 요청문을 **내가 직접 만들 수 있어야** 해요. 비밀은 **"결과물을 부품으로 쪼개고, 부품마다 시키는 문장을 거꾸로 쓰는 것"** 이에요.

**따라 하기**

**① 결과물 파헤치기 (4분)**

1. STEP 3의 **보고서 PDF(또는 웹페이지)** 를 보면서 아래 표의 5칸을 채워 보세요. (예시는 이미 채워져 있어요. **내 눈으로 확인한 것**을 한 줄씩 더하세요.)

   | 칸 | 물어볼 것 | 보고서 예시 |
   |---|---|---|
   | 영역 | 위에서 아래로 어떤 덩어리인가? | 제목 → 한 줄 결론 → 핵심 숫자 3개 → 3줄 요약 → 그래프 2개 → 다음 할 일 |
   | 눌러서 되는 것 | 버튼이 있나? | (없음. 인쇄용) |
   | 숫자 | 어떤 숫자가 어떻게 나왔나? | 비중 = 항목 ÷ 전체, 전월 대비 % |
   | 겉모습 | 글자 크기, 색, 용지는? | 글자 18px 이상, 색 3가지, A4 세로 |
   | 안 보이는 약속 | 인터넷 없이 되나? 틀린 데이터가 오면? | 외부 인터넷 금지, 숫자는 [재료]에서만 |

2. 막연한 말을 **재 볼 수 있는 말**로 바꿔 보세요.

   | 막연한 말 (나쁨) | 구체적인 말 (좋음) |
   |---|---|
   | "글씨 크게" | "글자는 18px 이상" |
   | "그래프 예쁘게" | "색은 3가지 이내, 값 이름표를 막대 끝에 숫자로" |
   | "인쇄도 잘 되게" | "A4 세로, 그래프가 쪽 사이에서 잘리지 않게, 화면의 버튼은 인쇄에서 숨겨" |

3. **틀린 곳이 나오면 규칙 한 줄을 더하세요.** 이것이 요청문을 키우는 방법이에요.

   | 이렇게 틀렸다 | 더할 규칙 한 줄 |
   |---|---|
   | 합계가 정답과 다르다 | "모든 합계는 코드로 계산해. 암산하지 마." |
   | 없는 숫자가 나온다 | "숫자는 [재료]에 있는 것만 써. 모르면 '자료에 없음'." |
   | 인쇄에 버튼이 찍힌다 | "화면에서만 보이는 버튼은 인쇄에서 숨겨." |

**② 내 업무 적용 로드맵 (3분)**

4. 회사에서 AX를 추진하는 순서는 이렇게 **4단계**예요. 내 업무 하나로 한 줄씩 써 보세요.

   | 단계 | 할 일 | 예시 (월 실적 집계) | 내 업무 |
   |---|---|---|---|
   | 1. **현황 진단** | 지금 업무와 데이터 상태를 본다 | 매달 25분 걸리고 중복으로 숫자 실수가 난다 | |
   | 2. **과제 발굴** (우선순위 정하기) | AI로 풀 과제를 찾아 순서를 정한다 | 1순위: 월 실적 집계 자동화 | |
   | 3. **시범 적용** (PoC) | 작게 먼저 해 본다 | 이번 달 한 번 앱①로 정리해 본다 | |
   | 4. **확산·정착** | 효과가 확인되면 넓힌다 | 다른 지점·부서에도 같은 정리 방법을 나눠 준다 | |

💡 **쉬운 설명/예시:** 새 식당을 낼 때와 비슷해요. 먼저 **동네를 보고(진단)**, **팔 메뉴를 고르고(과제 발굴)**, **작은 가게로 시험하고(시범 적용)**, **잘되면 지점을 늘립니다(확산)**. 처음부터 지점 10개를 내지 않는 것처럼, AX도 **작게 시험한 뒤** 효과가 숫자로 확인되면 넓혀요.
