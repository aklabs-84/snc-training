# 내 업무용 앱 만들기 · 빈칸 틀 카드

**결론:** 아래 【 】 세 곳만 내 업무에 맞게 바꿔 AI(ChatGPT 또는 Gemini)에 붙여 넣으면, 파일 하나짜리 앱 코드를 받을 수 있습니다.

## 바꿀 곳

| 바꿀 곳 | 내가 쓸 값 |
|---|---|
| 내 직무 | |
| 열 이름 (엑셀 표의 제목 그대로) | |
| 보여 줄 결과 | |

예) 내 직무: 생산관리 / 열 이름: 라인, 생산수량, 불량수량 / 보여 줄 결과: 라인별 불량률(%)과 전체 불량률 표

## 요청문

```
너는 제조 회사의 업무용
엑셀 도구를 만드는 개발자야.
【내 직무】 업무에 쓸
한 장짜리 웹페이지(HTML)를
만들어줘.

- 사용자가 엑셀에서 복사한 표를
  입력창에 붙여 넣는다
- 붙여 넣는 열 이름:
  【열 이름】
- 화면에 보여 줄 결과:
  【보여 줄 결과】
- 파일 하나로 끝나게
  (CSS와 JS도 안에 포함)
- 인터넷으로 데이터를 보내거나
  외부 주소를 부르는 코드는
  절대 쓰지 마
- 숫자에 쉼표가 있어도 계산되게
- 예시 데이터 3줄을 미리 넣어 줘
코드만 한 번에 보여줘.
```

## 앱이 열리지 않을 때

1. 코드를 복사해 메모장에 붙여 넣습니다.
2. 파일 이름을 `내업무앱.html`로 하고, 파일 형식을 **모든 파일**로 바꿔 저장합니다. (`.html.txt`가 되면 열리지 않습니다.)
3. 저장한 파일을 더블클릭합니다.

## 계산이 틀릴 때

```
계산이 틀려. 내 계산은 ○○인데
앱은 ○○으로 나와.
왜 그런지 설명하고
고친 코드를 전부 다시 보여줘.
```

## 외부 전송 확인

```
방금 만든 코드에 인터넷으로
데이터를 보내거나 받는 부분이
있는지 찾아줘.
(fetch, XMLHttpRequest,
외부 주소, 외부 스크립트 등)
있으면 줄 번호와 이유를,
없으면 "없음"이라고 답해줘.
```

AI가 "없음"이라고 답해도 메모장으로 `.html` 파일을 열어 Ctrl+F로 `http`와 `fetch`를 검색해 한 번 더 확인합니다.
