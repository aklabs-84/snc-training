# DESIGN.md — 엑셀 마스킹

확정일: 2026-10-22 / 시안 B(작업대)로 확정. 이 파일이 이 제품의 모든 화면 디자인 기준이다.

## 1. 목적과 사용자
- 화면 목적: AI에 보내기 전 엑셀·글 속 진짜 이름을 가리고, 답이 오면 되돌린다
- 주로 보는 기기: 사무용 PC(1280px 이상). 좁은 화면(390px)에서도 깨지지 않게

## 2. 레이아웃 유형
- 기본 유형: C 사이드바 앱형 (왼쪽 설정 360px, 오른쪽 작업면) + B 표·목록형(표 미리보기)
- 위쪽 탭: [가리기] [되돌리기]. 900px 이하는 설정이 위, 작업면이 아래로 쌓인다

## 3. 레퍼런스
- 가까운 것: 시안 B (2026-10-22 사용자 선택)

## 5. 컴포넌트 규칙
- 구분: 얇은 선 우선. 박스 안에 박스 금지
- 버튼: 주 버튼 1개만 주황 채움(2px 모서리), 나머지는 밑줄 글자
- 켜고 끄기: 사각 스위치(알약 금지). 선택 묶음은 사각 분할 버튼
- 입력창: 아랫줄만. 큰 글 입력은 1px 테두리
- 표: 한 줄 한 행, 위 2px 굵은 선, 호버 시 연한 주황 바탕

## 레이아웃 (2026-10-23, E안)
- 2단계 흐름: ① 파일 올리기 → ② 고르고·확인하고·저장. ②는 한 화면 두 칸(왼쪽 설정 360px, 오른쪽 결과). 왼쪽은 접을 수 있고(상태 기억), 900px 이하에서는 아래에서 올라오는 서랍(“설정 바꾸기”).
- 표 머리글은 조용하게: 칸 이름 + 작은 “그대로 · 추천”. 바꾼 칸은 주황 점 + “바꿈 · …”. 누르면 작은 메뉴(“이 칸을 어떻게 할까요?”).
- 저장 줄은 결과 칸 아래에 고정(sticky): 초록 확인 줄 + ① 주 버튼(주황) + ② 보조 버튼.
