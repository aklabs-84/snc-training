# 엑셀 마스킹 사용법

AI에 자료를 올리기 전에, **진짜 이름을 별명으로 바꿔 주는 도구**예요. 인터넷에 연결하지 않고 내 컴퓨터 안에서만 움직여요. (AI도 쓰지 않아요 — 정해진 규칙으로 바꿔요.)

## 여는 법
`엑셀 마스킹.html` 파일을 더블클릭하면 브라우저(크롬·엣지)에서 열려요. 설치는 필요 없어요. 파일 하나만 있으면 돼요.

## 엑셀 파일 가리기 (2단계)
화면 위쪽에 **① 파일 올리기 → ② 고르고 · 확인하고 · 저장** 순서가 보여요. 처음 열면 가운데에 사용법 창이 떠요. 다시 보려면 오른쪽 위 **사용법**을 눌러요.
1. **① 파일 올리기** — 큰 상자에 엑셀 파일(.xlsx 권장)을 놓거나 눌러서 골라요. 엑셀이 아닌 파일이나 시트가 없는 파일은 안내 문구가 떠요. 올리면 저절로 ②로 넘어가요.
2. **② 고르고 · 확인하고 · 저장** — 한 화면에 왼쪽은 설정, 오른쪽은 결과예요. 설정을 바꾸면 표가 바로 달라져요.
   - **왼쪽 "가릴 것"**: 이름·전화·메일 같은 종류를 켜고 꺼요. 처음엔 추천대로 켜져 있어요. 목록에 없는 이름은 칸에 직접 적어요. **접기 ◀**을 누르면 접혀서 표가 넓어지고, **⚙ 설정 바꾸기**로 다시 펼쳐요. (휴대폰에서는 아래에서 올라오는 창이에요.)
   - **표 맨 위 칸 이름**을 누르면 그 칸을 어떻게 할지 고르는 작은 메뉴가 떠요. 바꾼 칸은 주황 점이 붙어요.
     - **거래처 이름으로 / 사람 이름으로 가리기**: 칸 전체를 A사·담당자1 같은 별명으로
     - **글 속에서 찾아 가리기**: 메모처럼 긴 글에서 이름·전화·메일만 찾아서
     - **그대로 두기** / **지우기**
3. **가린 엑셀 저장**(→ `원본이름_가림.xlsx`)을 눌러요. 버튼은 화면 아래에 늘 보여요.
4. 저장하면 화면에 **AI에게 물어볼 말**이 나와요 (아래 "AI에게 물어보기"). 가린 엑셀만 AI에 올려요.
5. **별명표 저장**은 작은 링크예요. 나중에 AI 답을 진짜 이름으로 되돌리고 싶을 때만 눌러요. 별명표에는 진짜 이름이 있으니 AI에 올리지 마세요.

> 파일이 크면(약 1.5MB 이상) 가운데에 진행 창이 떠서 %와 숫자를 보여 줘요. 중간에 **취소**를 누르면 열어 둔 파일을 닫으니 다시 올리면 돼요. "표를 여는 중"은 %를 알 수 없어 빙글빙글만 돌고, 이때는 취소할 수 없어요.

### 큰 파일이 느릴 때
파일이 크면 열기·가리기·저장할 때 진행 창이 떠요. 열기·가리기는 %와 숫자가 나오고 취소할 수 있어요. 저장의 '엑셀 파일 만드는 중' 단계는 정확한 %를 알 수 없어서 움직이는 막대로 보여 줘요(취소 불가). 화면이 멈춘 게 아니니 잠깐 기다리세요.

## "내가 정한 말" 쓰는 법
| 하고 싶은 일 | 이렇게 적어요 | 결과 |
|---|---|---|
| 메일·전화 전체 가리기 | 적을 것 없이 **이메일/전화번호 스위치만 켜기** | `메일1`, `전화1` |
| 특정 말 가리기 | `프로젝트블루, 신제품X` (쉼표로 나눔) | `비공개1`, `비공개2` |
| 바뀔 말을 내가 정하기 | `프로젝트블루 → 알파` (`->`도 가능) | `알파` |
| 메일 한 사람 | `minsu.kim@ → 아크` (앞부분만 적어도 주소 전체) | `아크` |
| 한 회사 메일 모두 | `@novatech.co.kr → 노바` | `노바`, `노바2`… |
| 도메인이 제각각인 모든 메일 | `*@* → 메일숨김` (`*`는 "아무 글자나") | `메일숨김`, `메일숨김2`… |
| 010으로 시작하는 번호 전부 | `010-*` | `비공개1`… |

- 같은 바꿀 말을 여럿에 쓰면 2, 3…이 붙어서 되돌릴 때 헷갈리지 않아요.
- **숫자 칸에도 적용돼요.** 엑셀에 보이는 모양(예: `₩22,000`) 기준으로 찾아요. `₩*→가격`처럼 적으면 ₩ 표시가 붙은 금액만 `가격`, `가격2`…로 바뀌고, 말이 안 맞는 다른 숫자 칸(재고 수량 등)은 그대로 숫자로 남아요.
- 입력칸 아래 파란 줄에 바뀌는 모습이 바로 보여요. 왼쪽 판의 **“내가 정한 말” 쓰는 법 자세히 보기**를 눌러도 같은 안내가 있어요.

## 글 가리기
① 단계에서 **엑셀이 아니라 글을 가리고 싶어요**를 눌러 글을 붙여 넣어요. 사람·회사 이름은 ② 단계 왼쪽 칸에 적어 두어야 찾을 수 있고, 적으면 오른쪽 결과가 바로 바뀌어요. 마지막에 **① 가린 글 복사** → AI에 붙여 넣기.

## AI에게 물어보기
가린 엑셀을 저장하면 화면 아래에 복사해 쓸 질문이 나와요. 하고 싶은 일(거래처별 합계 / 메모 요약 / 납기 늦은 건 / 직접 쓰기)을 고르고 **질문 복사**를 누른 뒤, 가린 엑셀을 올린 AI 사이트에 붙여 넣어요.
> 첨부한 엑셀은 개인정보를 별명으로 바꾼 자료예요. A사·담당자1·전화1 같은 별명은 그대로 쓰고, 진짜 이름이나 번호를 추측하지 마세요. (하고 싶은 일) 답에도 별명을 그대로 써 주세요.

## 되돌리기 (필요할 때만)
AI의 답을 진짜 이름으로 바꾸고 싶을 때만 써요. 저장한 뒤 나오는 **AI 답에서 원래 이름 찾기 →** 를 누르거나, 첫 화면의 **AI 답을 진짜 이름으로 되돌리고 싶어요**를 눌러요. AI 답을 붙여 넣으면 별명이 진짜 이름으로 돌아와요. 이 도구는 AI에게 묻지 않아요. 별명표를 미리 저장해 두었다면 **별명표 불러오기**로 열어요. 돌아오려면 **← 가리기로 돌아가기**를 눌러요.
글(문장)만 되돌려 줘요. AI가 엑셀·표로 답한 것은 되돌릴 수 없어요.

## 꼭 지킬 것
- **별명표 파일에는 진짜 이름이 들어 있어요.** AI에 올리지 말고 내 컴퓨터에만 두세요.
- 가린 뒤 화면의 **⚠ 경고**를 꼭 읽어요. 이름·번호 모양이 남아 있으면 알려 줘요.
- 목록에 없는 이름은 도구가 알 수 없어요. 결과를 한 번 훑어보고 올리세요.
- 엑셀과 글을 같이 쓸 때는 **엑셀을 먼저** 가리면 별명이 서로 같아져요.

## 얼마나 정확한가요?
| 대상 | 정확도 |
|---|---|
| 거래처·사람 이름 칸 | 칸에 있는 이름은 모두 가려요 |
| 전화·메일·주민번호·사업자번호 | 모양이 정해진 번호는 거의 다 찾아요 |
| 내가 목록에 적은 이름 | 글 어디에 있어도 가려요 (띄어쓰기·대소문자가 달라도) |
| 목록에 없는 글 속 이름 | 못 찾을 수 있어요 → 경고로 알려 줘요 |

## 만든 사람용
- `src/core.js` 핵심 규칙 · `src/app.html` 화면 · `vendor/` 엑셀 읽기 라이브러리(SheetJS)
- 다시 만들기: `node build.mjs` · 자동 시험: `node test/test.mjs`
